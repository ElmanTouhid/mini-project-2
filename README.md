# Elman Touhid | Personal Portfolio

A personal portfolio website showcasing my background, interests, technical knowledge, and projects as a Computer Science student.

🌐 **Live Website:** [View My Portfolio](https://personal-portfolio-phi-three-92.vercel.app/)

💻 **GitHub Repository:** [Mini Project 2](https://github.com/ElmanTouhid/mini-project-2)

---

## 📌 About the Project

This portfolio website was developed as part of my Software Development coursework. It serves as a personal platform to introduce myself, showcase my interests in Computer Science, highlight my technical knowledge, and present projects I have worked on.

The website focuses on a clean, modern, responsive design with a dark theme and orange accents.

## ✨ Features

- **Home Section:** Personal introduction and welcome area.
- **About Section:** Background, interests, and approach to learning.
- **Skills Section:** Programming languages, Computer Science fundamentals, and technologies I'm exploring.
- **Projects Section:** Showcase of personal and collaborative projects.
- **Contact Section:** Direct email and GitHub links.
- **Responsive Navigation:** Separate navigation experience for desktop and mobile devices.
- **Smooth Scrolling:** Easy navigation between website sections.

## 🚀 Getting Started

To run this project locally:

**1. Clone the repository**

```bash
git clone https://github.com/ElmanTouhid/mini-project-2.git
```

**2. Navigate to the project directory**

```bash
cd mini-project-2
```

**3. Open the website**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
